# Harness² mobile reading script

Traditional Chinese speaker script for the 12-slide Harness² paper presentation.

- Complete merged-v2 script and a separate faster version.
- Continuous scrolling, clear slide boundaries, a persistent slide selector and adjustable text size.
- Per-slide supplementary questions and exact source references, collapsed by default.
- No analytics, external fonts, or runtime dependencies.

Paper: https://arxiv.org/pdf/2610.14224v1

Serve this directory with any static server, or publish the main branch root using GitHub Pages.
